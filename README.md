# XCOM Аналоги

Готовая независимая сборка помощника подбора аналогов XCOM-SHOP. Москва / Санкт-Петербург, цены от/до, сравнение характеристик, светлая и тёмная темы. 33 случайные уточки и одна иллюстрация для пустого результата.

## Запуск на Layero

Выбрать постоянный тариф Free, подключить этот репозиторий. Тип приложения node_web и команды записаны в layero.json. Карта и Pro для этой конфигурации не требуются по опубликованным условиям площадки.

Сборка: npm run build. Запуск: npm start. Проверка состояния: /healthz. Сервер слушает 0.0.0.0:$PORT (по умолчанию 10000). Зависимости для запуска не нужны.

Внешние запросы ограничены общим бюджетом 48 секунд на запрос. Непроверенные из-за лимита товары сохраняются в курсоре продолжения; поиск можно продолжить. Ошибка источника не считается отсутствием аналогов.

## Исходники и обновление

Архив xcom-release.tar.gz содержит standalone-dist с готовым сайтом и source с исходниками и тестами. Для самостоятельной пересборки распакуйте архив, скопируйте standalone-dist/public в source/public, выполните npm install и npm run build:standalone в source. Для изменений используйте именно эту версию: она включает ограничение времени для внешнего хостинга. Исходная версия в ChatGPT Sites сохранена отдельно.

Проверено: 62 автоматических проверки, включая прерывание медленной карточки и её повторную проверку после продолжения. Вход для сотрудников пока не реализован: подпись «Только для сотрудников» не ограничивает доступ. Характеристики, цены и наличие берутся из XCOM; дополнительные характеристики производителя и сравнение ОС/прошивки остаются в BACKLOG.md. Доступность из России проверяется на опубликованной ссылке.
