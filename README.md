# XCOM Аналоги

Готовая независимая сборка помощника подбора аналогов XCOM-SHOP. Поиск по коду, модели, артикулу и ссылке; Москва/Санкт-Петербург; цены от/до; сравнение; светлая и тёмная темы; 34 иллюстрации с прозрачностью.

## Запуск

Требуется Node.js 22.19 или новее. Сборка уже выполнена, установка зависимостей для запуска не нужна.

```sh
tar -xzf xcom-release.tar.gz
npm start
```

Сервер использует переменную PORT (по умолчанию 10000), слушает 0.0.0.0. Проверка состояния: /healthz.

Для Render: Web Service, Node, Free, build command `tar -xzf xcom-release.tar.gz`, start command `npm start`. Публикация сервиса выполняется отдельно: наличие этих файлов ещё не означает, что внешний сайт создан.

## Обновление

Архив содержит готовый клиент, сервер и исходники в source/. Рабочая версия исходного проекта сохраняется отдельно в истории XCOM Аналоги. После изменений архив пересобирается и заменяется, затем запускается повторное развёртывание. Для самостоятельной пересборки после распаковки скопируйте standalone-dist/public в source/public, перейдите в source и выполните `npm install`, затем `npm run build:standalone`.

Вход для сотрудников пока не реализован: надпись «Только для сотрудников» не ограничивает доступ. Характеристики, цена и наличие поступают только из XCOM. Работа внешнего адреса из России проверяется после развёртывания.
